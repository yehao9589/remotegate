# 设备与映射流量

设备工作台在设备信息下显示累计合计、上传和下载；展开“访问域名”，可查看每条映射自己的流量。计数跟随后台数据自动刷新，离线后保留。

## 趋势与排名

进入“运行概览”，选择设备或映射、全部对象或单个对象，可查看近 30 天的每日用量、近 12 个月的每月用量，以及所选期间前 10 名。展开明细可查看具体数值。

日期按 UTC 划分，最近 366 天的每日数据与累计值一起保存。趋势从启用此功能时开始记录，不会把升级前的累计流量分摊到过去日期；未统计、零流量和首日 / 首月不完整会分别说明。两类统计有包含关系，请勿把设备和映射汇总相加。

## 统计口径

- **上传**：服务端向设备内网发送的数据。
- **下载**：服务端从设备内网接收的数据。
- **映射**：该映射实际转发的 HTTP 请求和响应正文，包括目标网站返回的错误页面。被 RemoteGate 拒绝的访问、未发送成功的请求不计入；已发出但等待响应超时的上传仍计入。
- **设备**：实际归属于该设备的所有映射流量，加上 SSH、SFTP 通道数据（含这些协议自身的握手与封装）。

不计算 HTTP 请求/响应头、RemoteGate 控制消息和心跳，也不包含外层 TLS、WebSocket、TCP/IP 开销，因此与云厂商网卡账单的数字可能不同。SSH 和文件传输只计入设备，不计入某个网页映射。

统计按设备 ID 和映射 ID 保存。修改名称、备注、域名或目标地址不会清零；映射移到另一设备后，映射保留自己的累计历史，各设备保留实际经手的数据。删除映射不会扣减设备已经使用的流量，新建的新 ID 从零开始。

## 保存与升级

统计由服务端完成，不要求更新路由器插件。数据保存在 `STATE_PATH` 所在目录的 `traffic.json`，默认与账号、设备及映射一起位于持久化数据目录。

内存计数即时更新，每 5 秒原子写入文件，正常停止会完成最后一次保存。断电、强制结束或强制杀死容器时，可能丢失最近一个保存周期的数据；保存失败会保留内存计数并自动重试。

首次启用时记录统计起始时间，不推测此前的历史流量。重启或更新镜像时保留原数据目录，即可继续累计。页面只向已登录的管理员返回当前设备和映射的统计。
