# 网页 SSH 与文件管理

升级服务端和路由器插件后，可从设备卡片使用 SSH / 文件管理。
该功能默认开启，升级时缺少此选项的旧配置也使用默认值。
此前手动关闭的设置会保留，可在路由器「服务 → RemoteGate」重新启用。

## 连接

点击设备卡片的「SSH 终端」或「文件管理」，输入设备现有的 SSH
用户名及密码，或粘贴私钥（加密私钥还需密码）。
若目标 SSH 服务允许空密码，选择「密码」并留空即可连接；是否接受由目标服务决定。
后台默认连接路由器自身的 127.0.0.1:22，也可填写此设备能访问的内网
NAS 或其他 SSH 服务的地址和端口。

先检测主机指纹，和设备的 SSH 主机公钥指纹核对，勾选确认后再连接。
指纹变化会拒绝认证，不会自动跳过校验。
公网后台与插件服务端地址使用有效 HTTPS。本机后台预览可使用 HTTP；
插件连接内网 IP 地址时也允许 HTTP。

密码和私钥不写入服务端配置。会话仅对创建它的管理员登录会话可用；
关闭窗口、退出后台或闲置 15 分钟后释放连接。每台设备最多 4 条
TCP 管理连接，服务端最多 32 个已连接或正在连接的会话。
设备不需要向公网额外开放 SSH 端口。

## 网页面板的连接设置

管理员可在设备卡片的「设备管理 → 连接设置」调整每台设备的并发额度，
查看当前网页、实时连接用量和客户端实际容量。所有映射共享这台设备的额度，
SSH 与文件管理使用单独额度；普通用户不能修改连接设置。

初始配置允许 8 条实时连接，并为普通网页保留 8 条连接。
一个 MetaCubeXD 面板通常同时使用多条实时连接，多个标签会累计占用。
需要打开多个面板时，可选择「多面板 24 + 8」，再保存设置。
旧插件可能只支持 16 条总容量，界面会显示当前实际生效值；更高的目标值
可以先保存，升级插件后才会生效。

实时连接上限可填 1–124，网页保留连接可填 4–64，合计不超过 128。
调整只影响新建连接，降低上限不会强制断开已打开的面板。
「初始值 8 + 8」只填写最初的数值，不读取当前全局默认值，点击保存后才会应用。

工作台顶部的「全局连接设置」可以修改新增设备的默认额度。
直接保存只影响之后新增的设备，现有设备继续使用各自设置。
勾选「同时应用到全部现有设备」并确认后，会一次覆盖所有现有设备的额度，
包含离线设备、其他分页及筛选外的设备，同时保存新增设备的默认值。
界面显示的是全部设备数量，应用范围不受当前搜索或分页影响。
旧插件的实际容量限制仍然适用，设备上线后可在单台设备的连接设置中核对。

## 网页闲置自动暂停

连接设置中可分别调整「前台无操作后暂停」和「切到后台后暂停」，
也支持通过全局默认值或一次应用到全部设备设置。
默认前台 15 分钟没有点击、滚动或键盘操作后暂停，切到后台后给 1 分钟缓冲。
实时推送、自动刷新和心跳不会被当作人工操作续时。

暂停后关闭该页面的实时连接、阻止后续自动请求及重连，并显示「继续查看」。
点击按钮会重新加载页面并建立新的页面会话；仅切回标签页不会自动恢复耗流量的监控。
服务端同时检查页面会话的有效期，浏览器计时器被冻结时也会终止已过期的实时连接。
各标签页独立计时，设备隧道、后台 SSH / 文件管理及其他页面不随之退出。

此保护在通过映射加载标准 HTML 页面时启用。升级后需刷新原来已打开的网页一次；
支持 UTF-8 HTML 及 gzip 响应，不改写附件、JSON 或应用原有的 CSP 安全规则。
若目标应用的 CSP 禁止同源保护脚本，应按实际页面检查兼容性。
直接使用 API 的独立 WebSocket 客户端不视为网页会话。

## 文件管理

文件访问和命令执行权限取决于 SSH 账号。支持浏览、当前目录搜索、
下载、上传、新建文件夹、重命名及删除；删除目录仅支持空目录，
不会递归删除。

文件管理使用 SFTP。OpenWrt 默认的 Dropbear 需要配合
openssh-sftp-server；可在路由器软件包页面安装该组件。
详见 [OpenWrt SFTP 文档](https://openwrt.org/docs/guide-user/services/nas/sftp.server)。
不支持 SFTP 的设备仍可使用 SSH 终端。

上传单文件最多 4 GB，采用 256 KB 分片并校验接收位置，完整接收后
再提交目标文件。替换已有文件需再次确认，并要求 SFTP 服务支持
posix-rename 原子替换。替换时保留原文件的读写执行权限和所有者，
无法保留时拒绝替换。传输中断不会提交尚未完成的文件；
设备断线等情况下可能留有 .remotegate-upload- 开头的临时文件，
确认已无上传任务后可在文件列表中删除。

下载为流式传输，文件不整体读入服务端或浏览器内存。准备下载链接后
点击下载；链接使用一次后失效。终端组件随服务端自托管，
浏览器无需访问第三方 CDN。
