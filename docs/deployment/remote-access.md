# 网页 SSH 与文件管理

升级服务端和路由器插件后，可从设备卡片使用 SSH / 文件管理。
该功能默认开启，升级时缺少此选项的旧配置也使用默认值。
此前手动关闭的设置会保留，可在路由器「服务 → RemoteGate」重新启用。

## 连接

点击设备卡片的「SSH 终端」或「文件管理」，输入设备现有的 SSH
用户名及密码，或粘贴私钥（加密私钥还需密码）。
若目标 SSH 服务允许空密码，选择「密码」并留空即可连接；是否接受由目标服务决定。
后台默认连接路由器自身的 127.0.0.1:22，也可填写此设备能访问的内网
NAS 或其他 SSH 服务的地址和端口。

先检测主机指纹，和设备的 SSH 主机公钥指纹核对，勾选确认后再连接。
指纹变化会拒绝认证，不会自动跳过校验。
公网后台与插件服务端地址使用有效 HTTPS。本机后台预览可使用 HTTP；
插件连接内网 IP 地址时也允许 HTTP。

密码和私钥不写入服务端配置。会话仅对创建它的管理员登录会话可用；
关闭窗口、退出后台或闲置 15 分钟后释放连接。每台设备最多 4 条
TCP 管理连接，服务端最多 32 个已连接或正在连接的会话。
设备不需要向公网额外开放 SSH 端口。

## 文件管理

文件访问和命令执行权限取决于 SSH 账号。支持浏览、当前目录搜索、
下载、上传、新建文件夹、重命名及删除；删除目录仅支持空目录，
不会递归删除。

文件管理使用 SFTP。OpenWrt 默认的 Dropbear 需要配合
openssh-sftp-server；可在路由器软件包页面安装该组件。
详见 [OpenWrt SFTP 文档](https://openwrt.org/docs/guide-user/services/nas/sftp.server)。
不支持 SFTP 的设备仍可使用 SSH 终端。

上传单文件最多 4 GB，采用 256 KB 分片并校验接收位置，完整接收后
再提交目标文件。替换已有文件需再次确认，并要求 SFTP 服务支持
posix-rename 原子替换。替换时保留原文件的读写执行权限和所有者，
无法保留时拒绝替换。传输中断不会提交尚未完成的文件；
设备断线等情况下可能留有 .remotegate-upload- 开头的临时文件，
确认已无上传任务后可在文件列表中删除。

下载为流式传输，文件不整体读入服务端或浏览器内存。准备下载链接后
点击下载；链接使用一次后失效。终端组件随服务端自托管，
浏览器无需访问第三方 CDN。
