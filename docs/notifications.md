# 邮件通知

用自己的邮箱接收设备持续离线、证书临近到期、插件更新失败和恢复提醒。邮件默认关闭，站内提醒不受影响。

## 3 步启用

1. 在邮箱服务商处开启 SMTP，准备服务器地址、端口和授权码。
2. 进入 **账号与授权 → 邮件通知**，填写 SMTP、认证账号、发件邮箱和收件邮箱，保存。
3. 点击 **发送测试邮件**，确认收件箱收到邮件后，再启用自动通知并保存。

测试使用已经保存的配置，自动通知未启用时也可以测试。收件人最多 10 个，每行一个，彼此不会看到其他收件地址。

点击 **预览邮件**，在当前页弹窗中同时编辑模板、查看实际发送效果。左侧修改标题和正文，右侧实时预览，无需先配置 SMTP，也不会发送邮件。底下未保存的 SMTP 设置会保留；预览中的发件人、收件邮箱数量来自已保存设置。

## 自定义邮件内容

在弹窗顶部切换设备离线、证书到期、更新失败、恢复通知或测试邮件，各类模板分别保存。展开 **插入变量**，可点击插入设备名称、设备 ID、域名、异常标题、详情、状态、通知类型、记录时间、恢复时间、生成时间及本次通知数量。

点击 **保存模板** 仅保存当前类型，保存后仍可继续编辑和预览。**恢复默认** 先填入默认内容，保存后生效；**撤销修改** 回到当前类型已保存的内容。切换通知类型会暂时保留各自的草稿，关闭弹窗或离开页面会放弃未保存的模板草稿，不影响已保存模板和底下的 SMTP 设置。

变量使用 `{{device_name}}` 这样的格式，不适用时显示“—”，时间使用 UTC。标题最多 200 字，正文最多 10000 字；不支持的变量会提示错误。模板为纯文本，HTML 标签不会变成排版或脚本。多条通知仍合并发送，各条正文按对应模板拼接，合并标题自动显示通知数量；没有自定义的通知沿用默认内容。修改模板不会重新发送已经成功通知过的异常。

模板随 `mail.json` 保存，与 SMTP 配置分开修改。保存模板不会启用邮件或修改发件账号；预览草稿不会保存或发送。测试邮件也使用已保存的“测试邮件”模板。

| 设置 | 常见填写方式 |
| --- | --- |
| SMTP 服务器 | 邮箱提供的服务器域名，不写 `https://` 和端口 |
| 加密 | TLS 通常使用 465；STARTTLS 通常使用 587，以服务商说明为准 |
| 认证账号 | 通常为完整邮箱；免认证中继可留空 |
| 授权码 / SMTP 密码 | 通常是邮箱单独生成的授权码，不一定是网页登录密码 |
| 发件邮箱 | 服务商允许这个 SMTP 账号使用的发件地址 |

只支持加密连接，并验证服务器证书。SMTP 不提供 STARTTLS 或证书验证失败时，会停止发送，不退回明文认证。保存过的授权码不会回显；编辑时留空保留原值。

## 什么时候通知

- 设备连续离线超过 3 分钟。
- 最近检测到的证书剩余有效期不超过 30 天，或已经过期。
- 插件更新失败，包括已执行回滚的失败。
- 上述已通知异常恢复，或条件解除；删除相关配置也可能解除提醒。

可以分别开关通知类型。启用时会补发当前尚未通知的异常，不补发从未通知过的历史恢复记录。标记站内提醒已读不会阻止邮件发送。

后台把同一批待发提醒合并为邮件，成功结果会保存，普通重启不会重复发送已确认的通知。失败最多尝试 5 次，间隔逐步增加；修正设置后可点击“重试失败通知”。网络在服务器接收邮件后中断，或发送结果无法写入磁盘时，仍可能重试并收到重复邮件。

“发送成功”表示 SMTP 服务器已接受邮件，最终进入收件箱还受服务商过滤影响；可检查垃圾邮件和邮箱拦截规则。

## 数据保存

SMTP 设置和发送结果保存在持久化数据目录的 `mail.json`，文件以私有权限写入。SMTP 授权码需要用于后续发送，会保存在这个文件中；备份应按密码文件保管，不要公开分享。

只有管理员可以配置和查看邮件设置，普通用户无法读取 SMTP 信息。通知正文不包含设备令牌、后台密码或 SSH 凭据。
