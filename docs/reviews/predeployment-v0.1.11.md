## 已修复问题

1. **映射访问需要验证身份。** 新增和已有映射默认要求后台登录。每个映射使用独立、仅本主机有效的 HttpOnly 通行 Cookie；后台凭证和通行 Cookie 不进入内网网站。退出、过期和安全设置变化后撤销授权。详见[访问保护](../deployment/mapping-access.md)。
2. **回源目标可能被请求路径替换。** 拒绝绝对 URL 和带主机的请求路径；实际连接使用已检查的内网 IP，避免 DNS 再次解析绕过限制。显式允许公网目标的配置仍按原设置处理。
3. **隧道最大帧不足以承载 16 MiB 正文。** 帧大小现计入 JSON 的 base64 开销，客户端和服务端均限制接收帧。完整 16 MiB 请求和响应均已通过 WebSocket 隧道集成测试。
4. **SSH 通道初始化存在并发窗口。** 流控字段在通道发布前完成初始化。
5. **首次安装和旧插件升级可使用公网明文地址。** 新安装命令、首次升级命令和安装模板要求公网 HTTPS；回环地址和内网 IP 的本地测试允许 HTTP。
6. **构建和依赖安全更新。** 使用 Go 1.26.9，更新 SSH、HTTP、JOSE、ACME 及其相关依赖。升级参考 Go 官方公告：[HTTP/2](https://pkg.go.dev/vuln/GO-2026-6617)、[SSH](https://pkg.go.dev/vuln/GO-2026-6355)。

## 真实设备首次部署

1. 正式发布候选代码后，再更新服务器镜像，先停止服务备份完整 `/data` 和原编排配置；备份路由器 `/etc/config/remotegate`。
2. 保留现有正常工作的 443 反向代理及证书。管理地址建议显式设置 `PUBLIC_URL=https://实际后台域名`，不要包含后台入口路径。反代需传递原始 Host、HTTPS 协议和 WebSocket 升级信息。
3. 登录后台确认版本、设备在线和实际安装包为 `0.1.11-1`。已有映射会默认启用登录保护；公网 HTTP 保护映射需提供 HTTPS，公开网站可以明确选择公开访问。
4. 先升级一台非关键设备。核对设备身份、配置和映射保留；用另一浏览器确认未登录时受保护入口被拦截，登录后可访问。
5. 在该设备真实网络下验收路由器重启、网络恢复、OpenClash 节点失效/恢复，以及所需的 SSH / SFTP 功能。确认后再扩展到其余设备。

物理 ARM64 / ARMv7 路由器和真实 OpenClash 断网场景未在这轮执行。三种架构已构建并检查包内容，不能据此声称物理设备全部通过。插件当前要求 `opkg`，不包含 MIPS 或使用 `apk` 的新版 OpenWrt 支持。

回滚服务端应使用升级前固定版本及完整数据快照；不要删除数据目录或重置账号。客户端兼容回退仅支持同一客户端版本内的包修订号，不能依赖在线回退将 `0.1.11` 降回 `0.1.10`。
