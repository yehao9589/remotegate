# 设备状态与上下线记录

设备列表默认每页显示 10 台，可选择每页 5、10、20 或 50 台。搜索和在线状态筛选会查找全部设备，并回到第一页；定时刷新会保留当前页。置顶设备优先排列，删除设备后会自动调整页码。

设备卡片右上角的“刷新状态”只读取这一台设备的最新信息。已连接的设备还会检测隧道响应，最长等待 8 秒；离线设备也能刷新。此操作不会主动断开隧道，不需要升级插件。

连接存在但响应检测失败时，会提示本次检测未通过，保留真实连接状态。在线不代表路由器内网服务、域名或 HTTPS 入口一定可用，这些仍需要单独检测。

展开设备的“上下线记录”可查看最近 100 条记录，时间从新到旧排列，默认每页 10 条，可切换每页 20 或 50 条。每台设备分别保留当前页，记录刷新时不会跳回第一页。记录展开时随后台刷新定期读取，也可点击“刷新记录”。上线、下线、管理员重新连接和服务器停止分别注明。下线记录显示该次连接的已知在线时长；新连接替换旧连接时记录新的上线，旧会话退出不会把新会话标成离线。

记录在每次连接变化时与设备配置一起原子保存到 `STATE_PATH`，更新时保留原数据目录即可。重复处理同一会话的断开不会产生重复记录。删除设备时同时删除该设备的记录。

服务器正常停止会记录断开。异常停止后，下一次启动会记录“服务器重启时发现原连接已失效”，其时间是发现时间，不是推测的实际断开时间，因此不显示该次在线时长。启用功能前未保存的历史不会补填。所有记录和刷新接口仅供已登录的后台管理员使用。


## 一键诊断与异常提醒

在设备卡片点击“一键诊断”，可选择该设备的一条映射，分别检查设备隧道、公网 DNS、HTTPS 证书和内网 HTTP 响应。公网入口从服务端检测，内网服务通过已有隧道检测；诊断不会重启设备、修改网络或携带后台登录 Cookie。内网服务返回 401 / 403 时，仍需使用该服务自己的账号登录。

“运行概览”自动记录持续离线超过 3 分钟、证书 30 天内到期和插件更新失败的站内提醒。短暂重连不会每次生成提醒；已有异常会去重，条件解除后归档，再次发生时新增记录。重启后的短暂等待不会将已有离线提醒误报为恢复。

提醒最多保留 200 条，待处理项优先保留，支持未读筛选、全部已读和分页。提醒保存在原数据目录，不发送外部消息；删除相关配置也会解除其待处理提醒。证书检测暂时失败时，已有到期提醒不会直接被当成续期成功。

## 设备在线但网页卡住

在线表示隧道仍有心跳，不代表内网网页响应正常。公网带宽按最窄一段计算；服务器 5 Mbps 理论上约 0.625 MB/s，网页资源会共享这段带宽，隧道编码、TLS 及重传还会产生开销。

从 v0.1.20 起，新服务端与新插件协商后使用网页流式通道：边读边发，以字节窗口限制缓冲；取消页面请求会关闭对应内网连接。旧插件仍使用整包响应方式，需要同时升级才能启用新模式。保留登录保护与正文流量统计，不自动重放写入请求。

本机复现测试覆盖四条慢网页与另一映射并发、约 5 Mbps 慢读取、请求取消与过期写入；不等于已经确定生产现场根因。卡住时可检测隧道延迟，并查看内网服务响应和服务器带宽，区分连接拥塞、内网服务慢与隧道失去响应。
