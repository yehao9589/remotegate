# 普通用户授权

适合把部分设备分享给家人、同事使用。管理员维护设备，普通用户只使用获授权的服务。

## 添加一个用户

1. 管理员进入 **账号与授权 → 普通用户 → 添加用户**。
2. 填写账号、密码，可设置授权到期时间；留空为长期有效。账号为 3–32 个字符，支持中文（如“测试1”）、英文字母、数字及 `_ . -`，首位须为中文、字母或数字。密码至少 8 个字符且不超过 72 字节。
3. 勾选允许访问的设备。默认只能查看状态、流量、上下线记录和访问映射。
4. 确有需要时，单独勾选该设备的 **SSH 终端** 或 **文件管理**，保存。
5. 把原后台登录地址和这个账号交给用户。普通用户登录后自动进入“我的设备”。

最多创建 200 个普通用户，不开放自行注册。新添加的设备不会自动授予已有用户。

## 权限怎么生效

| 操作 | 管理员 | 普通用户 |
| --- | --- | --- |
| 查看设备状态、流量、上下线记录 | 全部设备 | 获授权设备 |
| 访问需要登录的映射 | 全部映射 | 获授权设备的映射 |
| SSH 终端 / 网页文件工具 | 可使用 | 每台设备分别授权 |
| 添加、编辑、删除设备与映射 | 可操作 | 不允许 |
| 更新插件、管理用户、修改设置 | 可操作 | 不允许 |

权限由服务端校验，修改网址或直接调用接口也不能访问未授权设备。已设为**公开访问**的映射仍对访客开放；如需按用户控制访问，请保留映射的登录保护。

远程工具仍需路由器插件启用，并使用目标服务自己的 SSH 账号。SSH 终端可以执行该 SSH 账号允许的全部命令；关闭网页文件工具不限制终端里的文件命令。网页文件权限包含浏览、上传、下载、重命名和删除。

## 撤销、停用与重置

在用户列表点击“编辑授权”“停用”或“删除”。修改授权、账号或密码后，该用户旧的后台登录、映射凭据和远程会话会被撤销，需要重新登录；其他账号不受影响。删除用户不删除设备与映射。

到期账号不能继续登录或发起新请求，现有远程会话由后台定期清理，最长约 30 秒。

账号、密码哈希和设备授权保存在持久化数据目录的 `admin.json`。更新时保留整个数据目录，备份文件不要公开分享。
